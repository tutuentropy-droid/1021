# 画脉通识 · 中国画知识学习系统

## 一、产品概念

### 1.1 核心价值

**画脉通识**是一套面向中国画爱好者与学习者的高效知识构建系统。它的核心使命是：

> 让用户像搭建知识树一样，按「朝代 → 流派 → 画家 → 经典作品 → 画论」的层级脉络，快速建立完整、系统的中国画认知框架。

传统的中国画学习往往面临三大痛点：
- **碎片化**：知识散落在画册、论文、网页中，难以形成体系
- **入门难**：面对千年画史，不知从何入手，缺乏清晰的学习路径
- **记不住**：画家、流派、技法众多，缺乏有效的记忆巩固机制

画脉通识通过**结构化梳理 + 对话引导 + 间隔重复抽认卡**三位一体的设计，将千年画史转化为可交互、可探索、可记忆的知识网络。

---

### 1.2 目标用户画像

| 用户类型 | 特征描述 | 核心需求 |
|---------|---------|---------|
| **艺术爱好者** | 对中国传统文化感兴趣，看过一些画展，但知识零散 | 建立系统认知，看懂画作背后的历史脉络 |
| **美术专业学生** | 中国画或美术史专业，需要备考或做研究 | 快速掌握重点画家与作品，辅助论文写作 |
| **书画从业者** | 书法、国画学习者，希望提升理论修养 | 理解传统画论，借鉴古人笔墨技法 |
| **通识教育者** | 中小学/大学教师，需要教学素材 | 获取结构化教学内容与互动课件 |
| **通识学习者** | 对传统文化有好奇心的普通白领 | 利用碎片时间高效学习，提升文化素养 |

### 1.3 核心交互方式

#### （一）知识树导航
- **可视化层级展示**：以朝代为根节点，向下展开流派、画家、作品
- **路径记忆**：用户浏览路径自动记录，形成"学习轨迹"
- **关联跳转**：从一幅作品可跳至同时代其他画家、同流派其他作品

#### （二）对话引导式学习
- **智能向导**：系统通过提问引导用户探索（如"您想了解山水画还是花鸟画？"）
- **苏格拉底式提问**：在作品欣赏中穿插启发式问题，促进深度思考
- **知识总结**：每次学习结束自动生成结构化笔记

#### （三）知识抽认卡（Flashcards）
- **多维度卡片**：
  - 人物卡：画家生平 + 代表作品 + 艺术风格
  - 作品卡：名画赏析 + 技法分析 + 历史背景
  - 流派卡：艺术主张 + 代表人物 + 传承关系
  - 画论卡：经典名句 + 出处 + 释义
- **间隔重复算法**：基于记忆曲线智能安排复习
- **收藏机制**：用户可标记重点卡片，形成个人知识库

#### （四）结构化梳理
- **时间轴视图**：纵向展示各朝代绘画发展脉络
- **流派关系图**：可视化展示画派之间的师承与演变
- **对比模式**：并排对比两位画家或两幅作品的异同

## 三、技术栈

- **后端**：Node.js + Express + TypeScript
- **前端**：React 18 + TypeScript + Ant Design
- **数据存储**：JSON 文件（便于快速迭代，后续可迁移至 PostgreSQL/MongoDB）
- **状态管理**：React Context + Hooks
- **可视化**：AntV G6（知识图谱）/ ECharts（时间轴）

---

## 四、快速开始

```bash
# 1. 安装依赖
npm run install:all

# 2. 启动开发环境（前后端同时运行）
npm run dev

# 3. 单独启动
npm run dev:server   # 后端: http://localhost:3001
npm run dev:client   # 前端: http://localhost:3000
```
